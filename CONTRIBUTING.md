# Guia de Contribuição

Obrigado pelo interesse em contribuir com este projeto.

Embora este repositório seja utilizado principalmente como projeto de estudo e portfólio, sugestões de melhorias, correções e otimizações são sempre bem-vindas.

## Como contribuir

1. Faça um fork deste repositório.
2. Crie uma branch para sua alteração.

```bash
git checkout -b feature/minha-melhoria
```

3. Realize as modificações.
4. Faça commits seguindo o padrão de Conventional Commits.

Exemplos:

```text
feat: adiciona organização por data

fix: corrige movimentação de arquivos ocultos

docs: atualiza documentação

refactor: simplifica regras de organização
```

5. Envie sua branch.

```bash
git push origin feature/minha-melhoria
```

6. Abra um Pull Request descrevendo as alterações realizadas.

---

## Boas práticas

Ao contribuir com o projeto, procure seguir os seguintes princípios:

- manter o código simples e legível;
- utilizar nomes claros para variáveis e funções;
- evitar duplicação de código;
- preservar a separação de responsabilidades entre os módulos;
- atualizar a documentação quando necessário.

---

## Reportando problemas

Caso encontre algum erro ou comportamento inesperado, abra uma Issue contendo:

- descrição do problema;
- passos para reproduzir;
- comportamento esperado;
- sistema operacional utilizado (quando aplicável).
